# CLI 说明要求

`ascend-env` 是本地应用入口，负责启动静态页面与本地服务、显示版本与帮助。下载、SSH、构建与容器管理等业务行为由 server 层模块实现，CLI 只负责装配与生命周期。

## 命令

```
ascend-env [命令] [选项]
```

| 命令 | 用途 |
| --- | --- |
| `start` | 启动本地服务并打开静态控制界面（默认命令） |
| `help` | 显示帮助 |
| `version` | 显示版本号 |

### `ascend-env start`

启动本地 HTTP/WS 服务，服务只监听回环地址，不对外暴露；浏览器访问 `http://127.0.0.1:<端口>`。

**选项**

| 选项 | 说明 | 默认值 |
| --- | --- | --- |
| `--host <地址>` | 监听地址，仅回环地址安全 | `127.0.0.1` |
| `--port <端口>` | 监听端口 | `6750` |

**示例**

```bash
npm run build      # 先编译服务并生成前端静态资源
npm start          # 等价于 node dist/cli/main.js start
# 或指定端口：
node dist/cli/main.js start --port 6750
```

**运行前提**

- 本机 Node.js 20+，并已执行 `npm install`。
- 启动前先 `npm run build` 生成编译后的服务与 `dist/web` 静态资源（启动时若缺失会给出警告）。
- 目标 Linux 服务器需安装 Docker 与可用的 Docker Compose，并允许 SSH/SFTP 访问。

**输出与退出码**

- `start` 成功后打印访问地址并持续运行，收到 `SIGINT`/`SIGTERM` 时优雅关闭后以退出码 `0` 退出。
- 参数错误（未知参数、非法端口、缺少参数值）打印错误到 stderr 并以退出码 `1` 退出。
- 端口被占用等服务启动失败打印错误到 stderr 并以退出码 `1` 退出。
- `help`/`version` 打印到 stdout 并以退出码 `0` 退出。

**常见错误**

| 现象 | 原因与处理 |
| --- | --- |
| `端口被占用` | 目标端口已有进程监听，用 `--port` 换一个端口。 |
| `未找到编译后的前端资源` | 未执行 `npm run build`，先构建再启动。 |
| `无法读取版本目录` | `catalog/catalog.json` 缺失或损坏，检查发布包完整性。 |

CLI 命令或参数变化时，同步更新本页、`--help`、README 与相应测试；相关测试覆盖帮助信息、参数校验、成功退出码和失败退出码。
