# CLI 说明要求

当前仓库尚未实现可执行 CLI。本页定义后续 CLI 的职责和文档标准；实际命令名称、参数与示例应随实现填写，不能把设计中的占位内容当作可运行命令。

## 职责

CLI 是本地应用的入口，负责启动静态页面与本地服务、显示版本和帮助信息，并在需要时暴露诊断入口。下载、SSH、构建和容器管理等业务行为调用[架构文档](architecture.md)中的应用模块，CLI 不维护另一套校验与执行逻辑。所有命令的关键操作和失败情况使用[统一日志](logging-design.md)。

## 每个命令必须说明

- 命令用途、语法、必填与可选参数、默认值及配置来源。
- 至少一个与当前项目场景一致的可复制示例，以及运行前提（本机或目标服务器需要什么）。
- 标准输出与错误输出的用途、退出码含义、常见错误及建议处理方式。
- `--help` 中可直接找到上述核心信息；README 提供最短启动方式，本页给出完整说明。

CLI 命令或参数变化时，同步更新本页、`--help`、README 与相应测试。相关测试至少覆盖帮助信息、参数校验、成功退出码和失败退出码；完成后运行完整测试套件。
